# homepage_practice3
## 概要
Web開発の基礎学習として制作したカフェのWebサイトです。  
参考書をもとに、HTML / CSS / JavaScriptの実装を練習しています。  
## 使用言語
- HTML：ページ構造やフォームの作成  
- CSS：レイアウト、配色、アニメーションの設定  
- JavaScript：クリック操作や選択内容に応じた表示の切り替え 
## ページ構成
- ホーム：メイン画像とカフェの紹介
- ニュース：お知らせ掲載用のページ（内容は今後追加予定）
- メニュー：料理・ドリンク・デザートの一覧
- 店舗情報：各店舗の住所・営業時間などの表示
- お問い合わせ：入力フォームの表示
## 主な実装内容
- ハンバーガーメニューの開閉  
- メニュー開閉時のボタンアニメーション
- チェックボックスによる商品カテゴリーの絞り込み
- 画像・説明文・価格を組み合わせたメニュー一覧
- テキスト入力、ラジオボタン、チェックボックスなどを使用したフォーム
## 学習内容
- HTMLによるページ構造の組み立て
## 目的
- フロントエンド開発の基礎理解    
- 学習した内容を自分で実装する力の向上
- ポートフォリオとしての活用

- スマートフォンなど、画面幅に応じたレイアウトの調整
- ニュースページの内容追加
